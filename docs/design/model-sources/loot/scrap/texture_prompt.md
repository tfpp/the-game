# scrap albedo

Built-in imagegen edit against uv_template.png. Runtime albedo is 128×128.

Use case: precise-object-edit. Asset: flat UV albedo for a scrap metal loot model. Preserve EXACT two rectangle locations and empty dark background in attached UV template. Large top rectangle RUSTED_SHEET: weathered grey-blue steel, broad orange-brown rust patches and flaking paint, chunky GoldSrc 1998 painted pixel detail, subtle broad scratches. Smaller lower-left strip BOLTED_STEEL: aged silvery steel with some dark oxidized spots for a hex nut and bolt; mostly consistent edge-safe material since many faces reuse this patch. Flat unlit albedo designed to reduce to128x128. No perspective, no 3D objects, no written text, no labels or border lines. Fill islands edge to edge.
