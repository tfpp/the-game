# crate albedo

Built-in imagegen edit of uv_template.png. Source retained here; runtime atlas is 128×128.

Use case: stylized-concept. Asset: precise-object-edit UV albedo atlas. Edit the attached UV template, preserving EXACT rectangle positions, sizes and empty dark background. Paint six weathered wooden shipping crate faces, one in each of the six square islands: thick framing boards, diagonal bracing, coarse brown wood planks, dark nail heads. Same aged wood palette all six faces. GoldSrc 1998 style: chunky painted pixels, broad details designed to survive reduction to 128x128. Flat unlit albedo, no perspective, no 3D render, no text, no labels. Fill islands edge-to-edge, retain all gutters. Square image.
