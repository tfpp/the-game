# Exterior prop sources

Triangulated OBJ exports, meter-scale dimensions, UV guides and the exact texture
prompts for the reviewed exterior set. Models and UVs were built before texture
generation. Each model has its own atlas with four padded material zones; repeated
faces intentionally reuse zones. Runtime PNGs live under `game/assets/street_props`.
Surface tiles have matching opposite boundary pixels and a suggested 2 m repeat.
