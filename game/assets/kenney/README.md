# Kenney asset packs

Unmodified packs by Kenney (www.kenney.nl), licensed Creative Commons Zero (CC0):
free to use in personal, educational and commercial projects; credit is appreciated
but not required.

- `game-icons/`, `game-icons-expanded/`: Game Icons and Game Icons Expansion
- `input-prompts/`: Input Prompts (pixel, 16x16 tiles)
- `prototype-textures/`: Prototype Textures
- `skyboxes/`: skybox panoramas
- `ui/`: UI Pack
- `ui-space/`: UI Pack - Space Expansion

The packs stay whole here. `scripts/export.sh` leaves out every file the game doesn't
reference (listed by `scripts/unused_assets.gd`), so exports stay small.
